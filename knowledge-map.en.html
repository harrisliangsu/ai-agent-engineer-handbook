Path A · New graduate / beginner (2–4 weeks)

Week 1: Engineering foundation concepts — L1 §1.1–§1.3 + glossary (LLM basics + Transformer) + A1–A11 Week 2: Prompting + RAG introduction — L1 §1.4 + L2 §2.4 + C1–C9 + D1–D5 Week 3: Agent concepts — L3 §1–§3 + E1, E2, E3, E5, E8 + translation Building Effective Agents (Chinese notes) (original) Week 4: Safety + practice — L1 §1.6 + I1, I2 + J7 (0-to-1 rollout path)

Path B · Mid-level (3–6 years, 1–2 months)

Foundations (already in place) → deepen: • All of categories A–F • Read L1–L4 straight through • Parts of G/H (system design + evaluation) • Read all 4 translations • Prepare category J behavioral answers from your own projects
